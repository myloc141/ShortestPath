# Workstream 01 - Seervada Network & Shortest Path

## Mục tiêu tổng quan

Workstream 01 tập trung vào việc phân tích và xử lý mạng Seervada Park bằng các thuật toán tìm đường đi ngắn nhất, kiểm tra tính hợp lệ của mạng, liệt kê tất cả đường đi và trực quan hóa kết quả. Dữ liệu gốc được lấy từ file `seervada_network.csv` và các script trong folder này được thiết kế theo từng bước: đọc dữ liệu → mã hóa đồ thị → chạy thuật toán → lưu kết quả và kiểm tra.

---

## 1) File dữ liệu đầu vào chính

- `seervada_network.csv`
  - Định dạng: CSV với các cột chính:
    - `node_u`
    - `node_v`
    - `distance`
    - `directed`
  - Đây là file dữ liệu gốc cho toàn bộ quá trình xử lý trong workstream01.
  - Các script chính đều đọc file này để tạo đồ thị, chạy thuật toán và tính đường đi.

---

## 2) Tổng hợp theo từng file

### 2.1. `Task1.py`

#### Input
- Đọc file: `workstream01/seervada_network.csv`
- Tham số/biến bên ngoài:
  - `CSV_PATH = "workstream01/seervada_network.csv"`
  - `source = "O"`
  - `target = "T"`
  - `nodes`, `edges`, `adj` được khai báo ngoài và cập nhật trong quá trình đọc file

#### Processing
- Đọc dữ liệu CSV và lưu vào `adj` (bảng kề), `edges` (danh sách cạnh), `nodes` (tập các nút)
- Xác định loại cạnh:
  - nếu `directed == "true"` thì lưu chỉ một chiều
  - nếu `directed == "false"` thì lưu theo cả hai chiều
- Kiểm tra:
  - node nguồn và node đích có tồn tại trong mạng hay không
  - tổng số cạnh
  - mạng có liên thông hay không (`nx.is_connected`)
  - trọng số có phải là số dương không
- Tạo ra các bản in ra console để mô tả đồ thị, danh sách kề và kết luận độ hợp lệ của mạng

#### Output
- In ra console:
  - danh sách node
  - danh sách cạnh và hướng đi
  - thống kê số node, số cạnh, cạnh vô hướng, cạnh có hướng
  - danh sách kề của từng node
  - kết luận mạng hợp lệ để chạy thuật toán
- Không ghi file CSV bổ sung

#### Downstream
- Đây là bước kiểm tra dữ liệu ban đầu, không có file output nào được các workstream khác đọc trực tiếp.
- File này phục vụ như một script phân tích nền cho các phần sau trong workstream01.

---

### 2.2. `Dijkstra.py`

#### Input
- Đọc file: `workstream01/seervada_network.csv`
- Tham số/biến bên ngoài:
  - `graph` được xây dựng từ các hàng trong CSV
  - `start` được gán bằng `"O"` trong main
- Cấu trúc dữ liệu chính:
  - `graph[u] = [(v, w), ...]`
  - `distances`, `prev` là các dict được tạo bên trong thuật toán

#### Processing
- Triển khai thuật toán Dijkstra bằng heap queue (`heapq`)
- Tính khoảng cách ngắn nhất từ node xuất phát tới tất cả các node trong mạng
- Dùng `prev` để lưu đỉnh đứng trước trên đường đi ngắn nhất
- Hàm `reconstruct_path()` sẽ khôi phục đường đi cụ thể từ `prev`

#### Output
- Trả về:
  - `distances`: khoảng cách ngắn nhất từ nguồn tới mỗi node
  - `prev`: node trước đó trên đường đi tối ưu
- In ra console:
  - khoảng cách ngắn nhất từ `source` đến `target`
  - đường đi cụ thể theo định dạng `A -> B -> T`

#### Downstream
- Đây là thuật toán cốt lõi cho các tiện ích phía sau trong workstream01.
- Không thấy script nào ở workstream khác đọc trực tiếp output của file này trong repo hiện tại.

---

### 2.3. `shortpath.py`

#### Input
- Đọc file: `workstream01/seervada_network.csv`
- Tham số/biến bên ngoài:
  - `CSV_PATH = "workstream01/seervada_network.csv"`
  - `source = "O"`
  - `target = "T"`
- Hàm `load_graph(filename)` tạo đồ thị từ file CSV

#### Processing
- Tạo `graph` theo cấu trúc `{u: [(v, w), ...]}`
- Gọi `dijkstra(graph, source)`
- Tìm đường đi ngắn nhất và trả về khoảng cách + path
- Sử dụng lazy deletion để xử lý các giá trị cũ trong heap

#### Output
- Trả về:
  - `dist` = khoảng cách ngắn nhất từ `source` đến `target`
  - `path` = danh sách node theo đường đi
- In ra console:
  - `Khoảng cách ngắn nhất từ O đến T: ...`
  - `Đường đi: ...`

#### Downstream
- File này là bản triển khai dạng “tìm một đường đi ngắn nhất” đơn giản, phục vụ kiểm tra logic thuật toán.
- Không tìm thấy output của file này được các workstream khác sử dụng trực tiếp.

---

### 2.4. `shortpath2.py`

#### Input
- Đọc file: `workstream01/seervada_network.csv`
- Tham số/biến bên ngoài:
  - `CSV_PATH = "workstream01/seervada_network.csv"`
  - `source = "O"`
  - `target = "T"`
- Hàm `load_graph(filename)`, `all_simple_paths(graph, source, target)`

#### Processing
- Dùng DFS để tìm tất cả đường đi đơn giản từ `source` đến `target`
- Với mỗi đường đi, tính tổng khoảng cách bằng `path_cost(graph, path)`
- Sắp xếp các đường đi theo `total_distance`
- Tìm các đường đi tối ưu có chi phí thấp nhất
- Có thể xây dựng `results` dạng metadata + list đường đi
- Ghi CSV với các cột:
  - `rank`
  - `source`
  - `target`
  - `path`
  - `total_distance`
  - `num_nodes`
  - `num_edges`
  - `algorithm`
  - `is_optimal`

#### Output
- In ra console:
  - số lượng đường đi khả thi
  - tổng khoảng cách tối thiểu
  - số phương án tối ưu
  - từng đường đi cùng khoảng cách tối ưu
- Ghi ra file:
  - `workstream01/results_paths.csv`
  - `workstream01/results_paths.json` (được định nghĩa trong phần `__main__`, nhưng hiện file JSON không xuất hiện rõ ràng như CSV trong repo)

#### Downstream
- File `tonghop.py` đọc trực tiếp `results_paths.csv` để lọc các đường đi tối ưu tương đương.
- Đây là output trung gian quan trọng cho các bước tiếp theo trong workstream01.

---

### 2.5. `tonghop.py`

#### Input
- Đọc file: `workstream01/results_paths.csv`
- Các cột quan trọng:
  - `total_distance`
  - `num_edges`
  - `path`
- Biến bên ngoài:
  - `PATH = Path(__file__).parent / "results_paths.csv"`
  - `output_path = folder / "equivalent_paths.csv"`

#### Processing
- Đọc toàn bộ các đường đi từ file output của `shortpath2.py`
- Tìm khoảng cách nhỏ nhất trong số các đường đi có trong file
- Lọc tất cả các đường đi có cùng `total_distance` nhỏ nhất
- Sắp xếp theo:
  1. số cạnh (`num_edges`)
  2. đường đi (`path`)
- Ghi ra bảng tổng hợp danh sách các đường đi tối ưu tương đương

#### Output
- Ghi ra file:
  - `workstream01/equivalent_paths.csv`
- In ra console:
  - `Minimum distance`
  - `Number of equivalent shortest paths`
  - danh sách từng đường đi tối ưu tương đương

#### Downstream
- Đây là output dạng “bảng tổng hợp cuối cùng” trong workstream01.
- Không thấy có workstream khác đọc trực tiếp file này trong repo hiện tại, nhưng đây là file chuẩn hóa để có thể dùng cho báo cáo hoặc bước downstream tiếp theo.

### 2.6. `doublecheck.py`

#### Input
- Đọc file: `workstream01/seervada_network.csv`
- Biến bên ngoài:
  - `source = "O"`
  - `target = "T"`
  - `G = nx.Graph()` để xây dựng đồ thị NetworkX

#### Processing
- Chạy Dijkstra của NetworkX: `nx.dijkstra_path()` và `nx.dijkstra_path_length()`
- Chạy brute-force bằng `nx.all_simple_paths()` và tính tổng trọng số từng đường đi
- So sánh khoảng cách tối ưu thu được từ 2 cách:
  - NetworkX
  - brute force

#### Output
- In ra console:
  - đường đi tối ưu do NetworkX tìm ra
  - khoảng cách tối ưu theo NetworkX
  - khoảng cách tối ưu theo brute force
  - số đường đi tối ưu
  - kết luận PASS/FAIL
- Không ghi file output

#### Downstream
- Mục đích là kiểm tra độ tin cậy của thuật toán chứ không phải sản sinh dữ liệu dùng cho workstream khác.

### 2.7. `viz.py`

- Biến bên ngoài:
  - `source = "O"`
  - `target = "T"`

#### Processing

- In ra console:
  - đường đi ngắn nhất

  - vị trí file ảnh đã được lưu

- Đây là output trực quan phục vụ báo cáo, thuyết minh hoặc kiểm tra nhận diện đường đi.
- Không tìm thấy workstream khác đọc trực tiếp file ảnh, nhưng nó có giá trị cho trình bày và phân tích trực quan.
